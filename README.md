# ピカピカ算数ランド

6〜7歳の子どもが遊びながら学べる、**さんすう・時計・そろばん**の練習サイトです。

問題は約150万通り以上をランダム生成するので、毎日ちがう問題で飽きません。
急かさない・まちがえても励まし合う設計で、「練習が楽しい！」と思える学習体験を目指しています。

## 特徴

### 🔢 さんすう
- 10まで / 20まで / 100まで / 1000まで（チャレンジ）の4段階
- たし算・ひき算・3つの数・かけ算入門
- 10・20まではドット表示で数える練習が可能
- 「おてほん」ボタンで考え方（指で数える・左から計算など）を確認できます

### 🕐 とけい
- じかんだけ → 30分ごと → 5分ごと → 1分ごとの4段階
- 「時計を読む」「時計を作る」「いまのじかん（実際の時刻で練習）」の3モード
- 短い針＝じかん / 長い針＝ふん、という読み方の基礎を練習できます

### 🧮 そろばん
- 本物のそろばんを画面でタップ操作できます（上の玉=5、下の玉=1つ1）
- 「数字を作る」「数字を当てる」「自由に遊ぶ」の3モード
- 1桁 / 2桁 / 3桁（チャレンジ）を切り替えられます

### 🎉 楽しさの仕掛け
- 7種類のキャラクターが応援台詞をランダムで出します
- 正解で紙吹雪・効果音・⭐ポイント（同じ端末内に保存）
- 10問正解でボーナス⭐5つ、9種類のシールを集められます
- 音量ON/OFFに対応

### 🔢 「数百万通り」の意味
- 100まで「3つの数」： 100×100×100 = 1,000,000通り
- 1000まで たし算ひき算： 約50万通り
- とけい（選択肢含む）： 約2,160通り、そろばん3桁： 900通り
- **合計で約150万通り以上**を、画面にもリアルタイム表示しています

## 使い方

`index.html` をダブルクリックすれば、そのまま遊べます（ビルド不要）。

ローカルでサーバーを立てたい場合は、次のどちらかをお使いください。

```bash
# Pythonを使う場合
python3 -m http.server 5173
# → http://localhost:5173 を開く
```

```bash
# Nodeを使う場合
npx serve .
```

### GitHub Pagesで公開する（一度だけ）

1. このリポジトリをGitHubにPushします（下記「開発」参照）
2. GitHubのリポジトリ画面で **Settings → Pages** を開く
3. **Source** で **GitHub Actions** を選択する
   - `main` ブランチにPushされるたびに `.github/workflows/pages.yml` が自動で公開します
4. 表示されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）で遊べます

## 技術

- `index.html` の1ファイルで動作（HTML + CSS + JavaScript）
- 外部ライブラリはGoogle Fontsのみ（読み込めない場合はシステムフォントにフォールバック）
- ゲームの進行（⭐・連Comb・シール）はブラウザの `localStorage` に保存され、外部送信されません
- 対応：スマホ / タブレット / PC
